Averages, not a forecast

Frost dates are 30 year climate normals. A given year can freeze earlier or later than the median. Nothing on this site is a weather forecast. Check a forecast if you need the next few nights.

Not professional advice

Planting notes repeat a state extension publication and, where the publication uses an offset, count that offset from the NOAA median. This is not legal advice, not insurance guidance, and not agricultural advice. Crop choice, elevation, soil, and a cold spring are yours to judge. The extension page and the station file outrank this summary if they disagree.

Stations and zones

The nearest station is not the same as every backyard in the city. A zone from the nearest ZIP code centroid can differ from a hill or a valley a few miles away.
